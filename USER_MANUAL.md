## 1. Огляд Платформи
Sentinel AI автоматизує аудит безпеки вашої інфраструктури, хмарних сервісів, контейнерів та мобільних додатків. Платформа не просто знаходить помилки, а й будує вектори атак та надає готові патчі (Terraform, Bash, kubectl).

---

## 2. Початок роботи
### Реєстрація та Вхід
1. Перейдіть на [https://santinelai.online/](https://santinelai.online/).
2. Використовуйте email та пароль для створення акаунту.
3. Після входу ви потрапите на **Dashboard**, де відображається ваш загальний Risk Score та статистика вразливостей.

### Головна панель (Dashboard)
- **Risk Score**: Показник безпеки вашої компанії (від 0 до 100). Чим він нижчий, тим краще.
- **SLA Breach**: Список вразливостей, термін виправлення яких згідно з вашою політикою (SLA) закінчився.

---

## 3. Управління проектами
Всі активи групуються за **Проектами**.
1. Перейдіть у розділ **Projects**.
2. Натисніть **New Project**.
3. Вкажіть назву, опис та ціль (IP-адреса, домен або репозиторій).
4. Оберіть тип середовища (External, Internal, Cloud, IaC).

---

## 4. Сканування вразливостей
Розділ **Scans** дозволяє запускати реальні перевірки.

### Типи сканерів:
- **Network (Nmap, Amass)**: Пошук відкритих портів та субдоменів.
- **Web (Nuclei)**: Перевірка веб-сайтів на OWASP Top 10.
- **Cloud (Prowler)**: Аудит безпеки AWS/GCP/Azure.
- **Containers (Trivy)**: Сканування Docker-образів.
- **Mobile (MobSF)**: Статичний аналіз APK та IPA файлів.

### Як запустити скан:
1. Натисніть **New Scan**.
2. Оберіть проект та тип сканера.
3. Натисніть **Start Scan**. Результати з'являться автоматично після завершення роботи агента.

## 5. AI Red Team та Kill Chain
Це одна з найпотужніших функцій Sentinel AI.
1. Оберіть проект у розділі **AI Red Team**.
2. Натисніть **Generate Kill Chain**.
3. Штучний інтелект проаналізує всі відкриті вразливості проекту і побудує інтерактивну мапу атаки за методологією **MITRE ATT&CK**. Ви побачите, як саме хакер може проникнути у вашу систему крок за кроком.

---

## 6. Аналіз ланцюжка поставок (SCA)
Для перевірки безпеки бібліотек у вашому коді:
1. Перейдіть у розділ **Supply Chain**.
2. Завантажте файл `package.json` або `package-lock.json`.
3. Система миттєво звірить ваші бібліотеки з базою **OSV.dev** (Google) і покаже всі CVE-вразливості з посиланнями на виправлення.

---

## 7. Пасивна розвідка та Dark Web
- **Passive Recon**: Використовує Shodan API для пошуку інформації про ваш домен без активного втручання в систему.
- **Dark Web Monitor**: Відстежує згадки про вашу компанію та витоки облікових даних на закритих хакерських форумах.

---

## 8. AI Copilot та автоматичне усунення
У розділі **Security Copilot** ви можете спілкуватися з AI-асистентом у форматі чату:
- *"Як мені закрити вразливість CVE-2023-1234?"*
- *"Створи скрипт для захисту мого S3 бакета."*

Біля кожної знайденої вразливості є кнопка **Remediate**, яка відкриває вікно з покроковим планом виправлення та готовим кодом.

---

## 9. API та CLI інструменти
Для автоматизації та інтеграції в CI/CD:
1. Перейдіть у розділ **API & CLI**.
2. Згенеруйте ваш **Personal Access Token**.
3. Використовуйте bash-клієнт `sentinel-cli` для запуску сканувань з термінала або GitHub Actions.

## 10. Налаштування та Інтеграції
### SLA (Service Level Agreement)
У налаштуваннях ви можете встановити час на виправлення вразливостей для кожного рівня критичності (наприклад, Critical — 1 день, High — 3 дні).

### Slack / Teams
Підключіть Webhook URL, щоб отримувати миттєві сповіщення про критичні загрози прямо у ваш месенджер.

## 11. Pre-release Quality Checklist (для команди)

Перед релізом або створенням Pull Request виконайте локальну перевірку якості:

```bash
npm run quality:check
```

Ця команда послідовно запускає:
- `lint` без warning-ів
- `typecheck`
- `test:run`
- `build`

Реліз або PR вважається готовим тільки після успішного завершення всіх етапів.
