# Batch 206: Автозапуск локального Agent на Windows

## Як було
- Агент можна було запустити вручну, але автозапуск після логіну не був налаштований.
- Початкова спроба створення Scheduled Task через `schtasks` була ненадійною і давала помилки.

## Що зроблено
- Додано службові скрипти в `sentinel-agent/scripts/`:
  - `run-agent.ps1` — безпечний запуск агента в background з перевіркою, що дубль-процес не стартує.
  - `stop-agent.ps1` — зупинка запущеного локального агента.
  - `install-autostart.ps1` — створення/оновлення Scheduled Task через `Register-ScheduledTask` для поточного користувача.
- Перевірено створення задачі `SentinelAgentLocal` та її запуск.
- Перевірено health endpoint: `http://127.0.0.1:9090/health` повертає `status: ok`.

## Що покращило/виправило/додало
- Агент запускається автоматично при логіні користувача на цій машині.
- Зменшено ризик ручних збоїв запуску після перезавантаження.
- Додано керовані локальні скрипти запуску/зупинки для підтримки.
