# Batch 209: Scans — прибрано хибний тривожний Demo-банер при онлайн агенті

## Як було
- На сторінці Scans великий верхній Demo-банер показувався для вибраного MOCK-скану навіть коли агент уже онлайн.
- Через це UI виглядав суперечливо: хедер показує `Agent online`, але сторінка сканів все одно сигналізує як про аварію.
- У хедері Scans бейдж `⚠ DEMO MODE` був занадто тривожним для історичного DEMO-скану.

## Що зроблено
- У [src/pages/Scans.tsx](src/pages/Scans.tsx):
  - додано перевірку доступності агента (той самий URL-джерело `agentHealthUrl` із localStorage, fallback на env/default);
  - верхній Demo-банер тепер показується лише коли `currentScanMode === 'MOCK'` **і** агент реально недоступний;
  - оновлено текст банера під цей сценарій.
- У [src/components/scans/ScanHeader.tsx](src/components/scans/ScanHeader.tsx):
  - пом'якшено бейдж режиму з `⚠ DEMO MODE` до `Selected Scan: DEMO`.

## Що покращило/виправило/додало
- При онлайн-агенті зник хибний критичний банер на Scans для історичних MOCK-сканів.
- Залишилась чесна індикація, що саме вибраний скан є DEMO, без конфлікту зі статусом агента в хедері.
- Перевірено якість: lint/build успішні.
