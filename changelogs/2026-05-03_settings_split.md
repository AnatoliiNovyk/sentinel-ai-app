# Settings.tsx Split — 2026-05-03

## Як було
- `src/pages/Settings.tsx` містив 1155 рядків коду (God object).
- Усе в одному файлі: профіль, підписки, SLA, збереження даних, агент, сповіщення, команда.

## Що зроблено
- Створено директорію `src/pages/settings/`.
- Винесено компоненти:
  - `SettingsProfile.tsx` — профіль користувача, сповіщення, команда, API ключі (~250 рядків).
  - `SettingsSecurity.tsx` — SLA конфігурація, збереження даних, агент, безпека (~350 рядків).
  - `SettingsSubscription.tsx` — підписки, плани PLANS, огляд акаунта (~300 рядків).
- Оновлено `Settings.tsx` — тепер містить тільки головний компонент з імпортами з модулів.

## Що покращило
- **Підтримка коду**: кожен файл має чітку відповідальність (~250-350 рядків).
- **Читабельність**: легше знаходити потрібний функціонал.
- **Тестування**: модулі можна тестувати ізольовано.
- **Архітектура**: відповідає патерну, застосованому для `Dashboard.tsx` та `Integrations.tsx`.
