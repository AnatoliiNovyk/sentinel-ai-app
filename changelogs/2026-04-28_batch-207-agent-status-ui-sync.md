# Batch 207: Синхронізація статусу Agent у UI

## Як було
- У `Settings` статус агента перевірявся по URL з `localStorage` (`agentHealthUrl`), а в хедері (`Agent offline/online`) використовувався окремий env/default URL.
- На сторінці `Scans` попередження `Demo Mode` могло "залипати" після зміни активного скану, бо стан вмикався лише в один бік.
- При первинному виборі скану часто обирався перший елемент списку, навіть якщо він був історичним `MOCK`-сканом.

## Що зроблено
- У `src/components/AppLayout.tsx`:
  - переведено `AgentStatus` на той самий source-of-truth URL: `localStorage('agentHealthUrl')` з fallback на env/default;
  - додано синхронізацію URL і регулярний poll зі стабільними hook-залежностями.
- У `src/pages/Scans.tsx`:
  - `showMockWarning` тепер синхронізується з `currentScanMode` в обидва боки;
  - для авто-вибору скану пріоритет віддається non-mock (`detected_mode !== 'MOCK' && !is_mock`) якщо такий є.

## Що покращило/виправило/додало
- Індикатор агента в хедері і статус у `Settings` стали консистентними.
- Зменшено хибні `Demo Mode`-сценарії через залиплий стан/автовибір історичного mock-скану.
- Перевірено якість після змін: `lint` і `build` проходять успішно.
